# Sarathi Owner Dashboard

ERPNext Owner Dashboard featuring:

- Executive commercial overview (Revenue, Expenses, Net Profit, Stock alerts)
- Interactive horizontal 5-stage manufacturing pipeline (BOM -> Production Plan -> Work Order -> Shop Floor Job Cards -> Stock Entry)
- 9 Dedicated Owner views (Owner Home, Projects, Project Detail, Customers, Sales Orders, Manufacturing, Stock & Quality, Finance, Reports)
- Full server-side RBAC and role enforcement
